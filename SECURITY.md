# Sécurité et confidentialité

Classe FR manipule des usages pédagogiques potentiellement sensibles. Le dépôt est public : ne publiez jamais de donnée personnelle, de document d'élève, de capture d'ENT, de message aux familles ou de pièce jointe identifiable dans une issue, une pull request ou un commentaire.

## Signaler un problème sensible

Pour une faille de sécurité, un risque de fuite de données ou un exemple contenant des informations identifiables, utilisez un canal non public du mainteneur ou la fonctionnalité de signalement de vulnérabilité privée de GitHub si elle est disponible sur le dépôt.

N'incluez pas de données réelles dans le signalement. Décrivez le problème avec un exemple fictif minimal.

## Portée

Les sujets attendus incluent :

- fuite ou exposition involontaire de données personnelles ;
- contournement des garde-fous de confidentialité ;
- instructions susceptibles d'encourager le dépôt de documents identifiables ;
- dépendance ou automatisation compromettant la confidentialité.

Les demandes pédagogiques ordinaires doivent passer par le formulaire de feedback enseignant.
